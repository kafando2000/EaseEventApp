# EaseEventApp

A Blazor event-planning dashboard for organizing celebrations, managing guest lists, and keeping upcoming events in view.

## Run locally

Requires the .NET 10 SDK.

```bash
dotnet run --project EaseEventApp/EaseEventApp.csproj
```

Open the local URL printed in the terminal. The dashboard includes sample events; events created in the form are kept in memory and reset when the app restarts.
